How to read / কীভাবে পড়বেন

Understanding the classification

G

Genus + Species

The scientific name has two parts: the genus (capitalised) and the species epithet (lowercase). Both are italicised.

উদাহরণ: Panthera tigris — Panthera = গণ, tigris = প্রজাতি।

T

The taxonomic ranks

Every animal sits in a nested hierarchy: Kingdom → Phylum → Class → Order → Family → Genus → Species. All taxa below belong to Kingdom Animalia.

সব প্রাণীই Animalia জগতের অন্তর্ভুক্ত।

R

Reading the tables

Each row lists common name, Bengali name, scientific name, and the full chain of phylum → class → order → family for that species.

প্রতি সারিতে পর্ব, শ্রেণি, বর্গ ও পরিবারসহ সম্পূর্ণ শ্রেণিবিন্যাস দেওয়া হয়েছে।
